# Phase 12.1/4 — Scanned Page OCR Pipeline, Preprocessing & Coordinate Alignment

**Goal:** ingest scanned PDFs, photocopies, and camera captures into Konusbitr with high-fidelity text extraction, accurate word-level bounding boxes aligned to the canonical top-left coordinate system, and per-page OCR confidence scoring — using an Apache-2.0 permissive CPU stack.

## Context

Phase 07 purposefully failed with `error_code: "needs_ocr"` when extractable text coverage fell below threshold across a document. Real-world corpora are dominated by scanned agreements, stamped receipts, invoices, and mixed PDFs where only certain pages are scanned.

This sub-phase implements the foundational OCR layer:
1. Moving from coarse document-level failure to **per-page quality tiering** (Tier 1 native text vs. Tier 2 OCR).
2. Introducing a **lightweight, permissive CPU OCR engine** (RapidOCR via ONNX Runtime, with Tesseract fallback) that requires no heavy GPU runtime or restrictive licensing.
3. Preprocessing degraded scans (deskewing, adaptive thresholding, denoising) to maximize OCR character accuracy.
4. Enforcing strict **word-level bounding box normalization** into PDF user-space points so citation highlights land exactly where human eyes expect them.

### 2. Permissive CPU OCR Engines

Konusbitr's default container image must remain strictly **Apache-2.0 compatible**. No AGPL or non-commercial model weights are permitted in this sub-phase:

1. **Primary Engine — RapidOCR (`rapidocr-onnxruntime`):**
   - Runs PP-OCRv4 detection and recognition models under `onnxruntime`.
   - Minimal CPU overhead, cross-platform (`linux/amd64`, `linux/arm64`), fast cold-start (<100ms), and Apache-2.0 licensed.
   - Configured through Docling's `RapidOcrOptions`.
2. **Fallback Engine — Tesseract 5 (`tesseract-ocr` / `pytesseract`):**
   - Used when RapidOCR confidence falls below `OCR_FALLBACK_THRESHOLD` (0.65) or for specialized scripts.
   - Configured through Docling's `TesseractOcrOptions`.

```python
# Engine selection contract
class OcrPipeline:
    def __init__(self, rapid_options: RapidOcrOptions, tesseract_options: TesseractOcrOptions):
        self.primary = RapidOcr(rapid_options)
        self.fallback = TesseractOcr(tesseract_options)

    def process_page(self, page_image: np.ndarray) -> OcrResult:
        result = self.primary.run(page_image)
        if result.confidence < 0.65:
            fallback_result = self.fallback.run(page_image)
            if fallback_result.confidence > result.confidence:
                return fallback_result
        return result
```

### 3. Image Preprocessing (`opencv-python-headless`)

Degraded inputs (mobile phone photos, skewed scans, faint receipts) undergo deterministic image preprocessing prior to OCR:

- **Rasterization:** Render PDF pages at 300 DPI using `pypdfium2` (Apache-2.0 / BSD-3).
- **Deskewing:** Calculate text orientation angle using minimum area bounding rectangles / Radon transform (`deskew` package); rotate if skew angle is between $\pm 0.5^\circ$ and $\pm 45^\circ$.
- **Binarization & Contrast:** Apply adaptive Sauvola or Otsu thresholding for uneven lighting and shadows.
- **Denoising:** Bilateral filtering to preserve character edges while eliminating paper grain and scanner noise.
- **DPI Normalization:** Rescale images under 150 DPI up to 300 DPI equivalent before OCR feature extraction.

### 4. Bounding Box Normalization (`docs/coordinates.md`)

OCR engines return pixel coordinates relative to the 300 DPI raster image with origin at top-left. Konusbitr requires all bounding boxes to be stored in **PDF user-space points (1/72 inch)**:

$$\text{scale} = \frac{72.0}{\text{DPI}}$$
$$x_{\text{pdf}} = x_{\text{pixel}} \times \text{scale}, \quad y_{\text{pdf}} = y_{\text{pixel}} \times \text{scale}$$

- **Format:** Strict 4-tuple `[x0, y0, x1, y1]` (left, top, right, bottom) where $x_0 < x_1$ and $y_0 < y_1$, origin top-left, $y$ increasing downward.
- **Page Rotation:** Apply page transformation matrices for documents with native rotation tags (90°, 180°, 270°) so that coordinates represent unrotated physical page space.
- **Word & Line Merging:** Group word-level OCR bounding boxes into sentence/paragraph blocks while retaining word offsets for exact citation highlighting.
